# sd-pro-prompts

Curated collection of high-quality **人物微表情 (micro-expression)** prompts for **Seedance 2.5** and **MiniMax H3**, sourced from real posts on X (Twitter).

> All prompts are collected with full attribution. No fabricated content.

## Structure

- [`prompts/micro-expressions.md`](prompts/micro-expressions.md) — Main collection of micro-expression prompts (with sources, dates, and original authors)

## Models Covered

- **Seedance 2.5** (ByteDance) — Excellent at continuous micro-expression chains, tear build-up, restrained emotion
- **MiniMax H3 (Hailuo H3)** — Strong facial realism and natural expression transitions

## How to Use

1. Copy the prompt you need
2. Prefer using reference images for character consistency
3. For Seedance 2.5: timed action chains + millimeter-level control work best
4. For MiniMax H3: structured SUBJECT / ACTION / ENVIRONMENT blocks or timed beats perform well
