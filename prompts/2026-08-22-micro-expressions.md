## 1. Seedance 2.5 — Cigar lounge couple dialogue with detailed micro-expression performance (雪茄休息室情侣对话)

**Source**: [@Chengzilhy](https://x.com/Chengzilhy)  
**Model**: Seedance 2.5  
**Original post URL**: https://x.com/Chengzilhy/status/2091053625380642982  
**Date**: 2026-08-22

**Full prompt** (shared directly in the post):

```
｜雪茄休息室情侣对话｜

参考上传人物图片，生成一段 30.00 秒、9:16 竖屏、高质量超写实真人情侣互动短片。

整体视觉：

高级私人雪茄休息室 × 男友手机第一视角 × 黑发冷艳女友 × 自然情侣调侃 × 近距离真人手持记录感。

整条视频只有上传图片中的 同一位成年女性角色 出镜。

人物表演始终遵循：

听见男友说话 → 短暂停顿 → 眼神先产生反应 → 表情变化 → 自然回答。

所有动作均由对白推动。

【强制约束｜人物】

严格保持上传图片中的同一位成年女性角色。

全程保持：

同一张脸、同一五官、同一黑色长发、同一肤色、同一身材比例、同一年龄感。

完整保持参考图片中的造型：

黑色长直发

面部两侧自然碎发
细窄金属框眼镜
金色耳饰
黑色高领修身长袖上衣
黑色修身长裤
黑色皮质手套
黑色高跟短靴
女主整体气质：

冷静、漂亮、成熟、略带傲娇。

她与摄影机后的男友非常熟悉，表现为真实情侣之间自然被逗、忍笑、笑场、怀疑和反击的状态。

【场景】

高级私人雪茄休息室。

背景为：

暖金色灯光照亮的整面玻璃雪茄陈列柜、整齐排列的雪茄、黑色 Chesterfield 真皮沙发、深色木质地板。

整体颜色：

黑色 × 深棕色 × 暖金色。

真实室内暖光。

人物面部曝光自然清楚，背景保持柔和偏暗。

【摄影机】

摄影机始终代表：

男友手中正在拍摄女友的手机。

约 24–28mm 手机广角镜头感。

全程保持轻微真实手持：

微小呼吸感、微小位置漂移、人物运动后摄影机自然跟随。

摄影距离变化：

中景 → 缓慢靠近 → 手套扫过镜头 → 中近景 → 脸部近景 → 极近人像 → 最后轻微后退。

镜头始终保持情侣之间随手拍摄的真实亲密距离。

【0.00–3.50秒｜看这里，笑一个】

开场中景。

女主自然 双膝跪坐在黑色皮沙发前方地面。

双腿自然折叠，一侧小腿与黑色短靴向画面侧边露出。

她双手托着一个：

浅木色长方形雪茄展示盒。

盒内只有一支雪茄。

女主开场低头看雪茄。

男友在摄影机后自然说道：

男友画外音：

“诶，看这儿——笑一个。”

女主听见声音后停顿半拍。

眼睛先抬起看向镜头，随后头部才缓慢抬起。

她看着男友，给出一个轻微、略显敷衍但自然的浅笑。

随后回答：

女主：

“嗯……这样？”

摄影机开始缓慢向她靠近。

【3.50–7.50秒｜男友翻旧账】

男友继续说道：

男友画外音：

“跟你第一次给我点雪茄那天一样。”

女主听完短暂停顿。

眼神依次出现：

意外 → 想起来了 → 有点不服气。

她轻轻抿嘴，下巴微微抬起。

看着镜头回答：

女主：

“那能一样吗……我那是在服务。”

前半句还保持认真。

说到后半句时，嘴角已经开始轻微上扬。

摄影机继续靠近。

【7.50–11.30秒｜忍笑、笑场、手套扫镜头】

女主本来还想维持冷静。

先出现：

抿嘴忍笑。

随后呼出一口气。

终于自然笑出来：

女主：

“呵……”

她转头笑一下，又重新看向男友。

带着“你怎么还记得”的感觉说道：

女主：

“……你还提这个。”

笑的时候身体自然轻微前倾。

随后她抬起一只戴黑色手套的手。

像情侣之间玩闹一样朝摄影机伸过来。

约10.7–11.3秒

黑色手套快速靠近手机镜头。

手掌从镜头前方自然扫过：

遮住大部分画面 → 产生短暂近距离运动模糊 → 立即离开。

摄影机随她伸手的动作产生一次自然轻晃。

整个动作连续完成，不停留。

【11.30–18.80秒｜从笑场逐渐变成疑惑】

手套离开后重新看到女主。

摄影距离已经更近。

她脸上仍残留刚刚笑过的表情。

前几秒保持自然余笑，并继续看着男友。

随后男友突然用稍微认真一点的语气说道：

男友画外音：

“诶别动，你嘴角有烟灰。”

女主听到以后：

笑意缓慢收住。

眼神从放松逐渐变成疑惑。

她稍微低眼检查一下自己。

然后重新看镜头：

女主：

“嗯？”

停顿。

她开始主动向手机靠近。

把男友的手机镜头当成镜子。

随后问：

女主：

“……哪儿？”

摄影机进入脸部近景。

【18.80–24.30秒｜认真检查嘴角】

女主已经非常靠近镜头。

脸部成为画面主体。

她认真盯着手机镜头检查自己。

一只戴黑色手套的手缓慢抬起来。

动作依次完成：

手指靠近嘴唇

→

轻轻触碰一侧嘴角

→

擦一下

→

手离开嘴角

→

低眼看自己的黑色手套指尖

→

重新看向手机镜头

→

轻轻抿一下嘴唇

→

再次确认刚才触碰的位置。

动作幅度始终很小。

表情保持：

疑惑、认真、有一点在意自己的形象。

手始终围绕：

嘴角 → 指尖 → 嘴角

这一条动作路径进行。

摄影机保持极近人像距离。

【24.30–26.50秒｜沾了一点危险】

就在女主仍然认真确认嘴角时。

男友短暂停顿。

随后说道：

男友画外音：

“……沾了一点危险。”

女主听到这句话以后：

手部动作立刻停住。

短暂停顿。

她开始理解这句话真正的意思。

眼睛先缓慢向侧面移动。

形成一个明显的侧目。

嘴角出现极轻微、压住笑意的变化。

随后眼睛重新移动回来，看向摄影机后的男友。

这一刻的情绪是：

“原来你刚才是在逗我。”

【26.50–30.00秒｜扶眼镜反杀】

女主重新恢复冷静。

她脸上仍保留极轻微被逗到之后的笑意。

戴黑色手套的手缓慢抬起。

手指自然碰到细金属框眼镜。

轻轻调整眼镜。

与此同时摄影机开始缓慢向后退。

人物从极近脸部重新回到胸部以上构图。

女主身体缓慢转向侧面。

随后：

下巴轻轻低下。

停顿半拍。

眼睛先抬起。

透过眼镜重新直视摄影机后的男友。

最后说道：

女主：

“……你知道自己在说什么吗？”

说完保持最终 Pose：

身体轻微侧身 + 黑手套停留在眼镜附近 + 下巴微低 + 眼睛直视镜头。

稳定停留至视频结束。

【表演节奏】

女主所有反应都保持：

先听见 → 停顿 → 眼睛反应 → 表情变化 → 再说话。

人物动作以：

眼睛、嘴角、眉毛、下巴、头部、手腕、手指

为主要表演区域。

身体只进行轻微重心变化。

每一个明确动作按照：

进入动作 → 动作到位 → 极短停顿 → 下一动作

自然衔接。

重点动作顺序：

低头看雪茄

→ 抬眼看男友

→ 敷衍浅笑

→ 嘴硬解释

→ 忍笑

→ 彻底笑场

→ 手套快速扫过手机镜头

→ 笑意逐渐收住

→ 靠近镜头检查嘴角

→ 擦嘴角

→ 看手套指尖

→ 抿嘴确认

→ 听见“危险”后停住

→ 侧目

→ 重新看男友

→ 扶眼镜

→ 侧身

→ 低头

→ 抬眼反杀。

【对白与声音】

所有对白使用自然中文。

女主对白必须与嘴型自然同步。

男友始终位于摄影机后方，只出现声音。

男友声音距离手机较近。

两个人说话保持真实情侣聊天状态：

自然、松弛、有停顿、有轻微调侃感。

无 BGM。

保留真实同期声音：

室内轻微环境底噪

空调声

人物呼吸

衣料摩擦

皮手套摩擦

手套接近手机产生的轻微声音

女主真实笑声

男友近距离画外对白
```

## Usage Tips

- Strong pattern in today’s top prompt: **hear → pause → eyes react first → expression change → speak**. This sequence produces highly natural micro-expressions on Seedance 2.5.
- Lock the exact reference character (face, hair, outfit, gloves, glasses, etc.) and keep the same identity across the entire 30 s.
- Use first-person handheld phone POV + progressive push-in / pull-back to keep the performance intimate and readable.
- Time-segment every beat (0.00–3.50, 3.50–7.50 …) and describe the precise emotional arc inside each window (忍笑 → 笑场 → 疑惑 → 侧目 → 反杀).
- Micro-movements should stay small (mouth corners, side-eye, fingertip wipe, glasses adjustment). Body only does light weight shifts.
- Dialogue-driven performance works especially well: every action is triggered by the off-screen partner’s line.
