## 1. Seedance 2.5 — Suppressing laughter / trying not to laugh (憋笑微表情)

**Source**: [@jarvis11x](https://x.com/jarvis11x)  
**Model**: Seedance 2.5  
**Original post URL**: https://x.com/jarvis11x/status/2090116654373970411  
**Date**: 2026-08-19

**Full prompt** (from author’s reply):

```
4-8秒：笑声开始不受控制地涌上心头。她努力保持面部表情静止，但努力还是在一些细微之处显露出来：她的嘴唇抿得有些紧，下巴绷得更紧，眨眼的频率也加快了。她小心翼翼地从鼻子里呼出一口气，试图让自己镇定下来。这几乎奏效了——然后，她下唇微微颤抖了一下，眼睛先于嘴角露出笑容，一丝暖意涌入她的眼眸，而她脸上的其他部位则努力保持镇定。

8-12秒：她终于忍不住了。一声轻微的哼声从鼻子里逸出，这声音本身就彻底击垮了她——无声的笑声爆发了，她整张脸都因喜悦而扭曲，眼睛眯成弯月，鼻子皱起，肩膀抖动。她用手掌捂住嘴巴，低下头，马尾辫甩来甩去，试图躲在镜头下方，而她的肩膀仍在颤抖。

12-16秒：她重新出现在镜头前，气喘吁吁，用一只手扇着自己发烫的脸颊。眼角闪着笑出的泪光。她夸张地深吸一口气，从圆润的嘴唇间吐出，努力挺直身子——但她的嘴唇却不停地抽动，最后一声断断续续的轻笑脱口而出，让她自己都感到一阵难堪。

16-20秒：无声的道歉。她努力抑制住即将绽放的笑容，双手合十放在胸前，指尖向上，做了一个小小的祈祷手势。她微微歪着头，皱了皱鼻子，露出一个羞涩而又自嘲的笑容，然后向前鞠了一躬，对着镜头轻轻点头致歉——鞠躬时，她轻轻闭上了眼睛，几缕碎发垂落下来。她重新站起身来，双手依然紧握，嘴唇微微合拢，带着一丝羞涩的微笑，双眼依然湿润闪亮，最后轻轻地从鼻孔呼出一口气。

[画质与视觉细节]
正面固定镜头，柔和的自然光线从前方照射，在她颧骨上营造出轻柔的阴影。逼真的肌肤纹理，笑声中泛起淡淡的红晕，笑泪闪烁，双眼细节丰富，眼神自然，牙齿清晰可见，细碎的碎发随着她低头鞠躬的动作而飘动。喉咙、下巴、嘴角和眉毛的细微动作清晰可见——她脸上每一个抑制的瞬间都跃然纸上。8K分辨率，大师级画质。电影级的情感特写肖像。画面中的女性与输入图像中的女性相同，在整整20秒内保持相同的固定正面镜头角度和构图，如同在正式视频通话中通过网络摄像头拍摄一般。固定机位，静态拍摄，无摇摄，无缩放，一镜到底。没有音乐，只有安静的房间环境——轻柔的呼吸声、细微的压抑鼻音、布料的沙沙声。没有对话，没有口型，没有类似说话的唇部动作。

这是她这辈子最努力憋笑的一次。抑制笑声的过程缓慢而迟缓，然后像潮水般一波接一波地袭来：她几乎就要成功，然后失败，最后彻底失败。

[时间线及表情变化] 

0-4秒：她端坐，神情平静、专注、沉着，目光略微落在镜头下方，仿佛在观看共享屏幕。她的目光短暂地瞥向一侧——她注意到了什么——然后又回到原位。片刻之后，她什么也没注意到。她的表情保持​​平静。然后，她缓缓地咽了口唾沫。她的目光下垂了半秒钟。嘴角微微向一侧抽动了一下，然后又轻轻地将嘴角放平。
```

## 2. Seedance 2.5 — Micro-expression writing method for the same line with 7 different emotions (心动 / 欣喜 / 温柔 / 笃定 / 不舍 / 苦涩 / 执念)

**Source**: [@MrLarus](https://x.com/MrLarus)  
**Model**: Seedance 2.5  
**Original post URL**: https://x.com/MrLarus/status/2090410348356481264  
**Date**: 2026-08-20

**Author’s method (prompt structure)** (from author’s reply):

```
提示词方法：

先用参考图锁定人物的脸、发型、服装、场景、光线和机位，后面只改变表演，不改变角色本身。

每一种情绪都当成一场独立的小戏来写，不要只告诉 AI“她很开心 / 很委屈 / 很执着”，而是把人物为什么会产生这个情绪写清楚。

我一般会按这个顺序：

情境触发 → 第一反应 → 眼神神态 → 呼吸 / 身体动作 → 台词 → 台词后的余韵

比如「不舍」不是只写“眼眶湿润”，而是：

对方准备离开 → 她下意识追出半步 → 抬手想挽留又停住 → 强撑着笑，眼眶慢慢泛湿 → 说「我会等你」→ 目光继续追着对方，笑意一点点消失。

重点把视线、呼吸、嘴角、停顿、手部动作、身体重心这些真实演员会有的反应写进去。

核心就是：

要把这场戏为什么发生、人物怎么反应、最后怎么说出来，一起写清楚。
```

**Note**: This is an updated method post from the same author who previously shared a 7-emotion set (羞嗔 / 傲娇 / 闷气 / 警告 / 心冷 / 委屈 / 挣扎) on 2026-08-14. No full ready-to-copy multi-segment prompt text was shared in the new post beyond the structural method and the “不舍” example above.

## Usage Tips

- Time-segmented physiological sequences (lip tension → jaw → eye leak → full break) work especially well for suppressed emotions such as holding back laughter.
- Lock identity + camera first; vary only performance and internal trigger.
- Write the *reason* for the emotion (situational trigger) rather than only the emotion label.
- Sequence recommended by practitioners: trigger → first physical reaction → eyes/gaze → breath/body → line → residual reaction after the line.
- Fixed frontal webcam-style shot helps keep micro-expressions readable across 15–20 s.
