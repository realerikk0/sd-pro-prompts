## Usage Tips (carried forward)

- Strong pattern that continues to perform well: **hear → short pause → eyes react first → expression change → speak**. This sequence produces highly natural micro-expressions on Seedance 2.5.
- Lock the exact reference character (face, hair, outfit, accessories) and keep the same identity across the entire clip.
- Use first-person handheld phone POV or fixed intimate framing + progressive push-in / pull-back to keep the performance readable.
- Time-segment every beat and describe the precise emotional arc inside each window.
- Micro-movements should stay small (mouth corners, side-eye, fingertip movements, glasses adjustment, breath). Body only does light weight shifts.
- Dialogue-driven performance works especially well: every action is triggered by an off-screen or on-screen partner’s line.
- Write the *reason* / situational trigger for the emotion rather than only the emotion label.
- Prefer one continuous take or minimal cuts so micro-expressions remain readable.
- Keep tears gathering and falling under gravity rather than appearing suddenly.
